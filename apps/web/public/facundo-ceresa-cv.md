# Facundo Ceresa - CV técnico

Montevideo, Uruguay

## Perfil

Desarrollador full-stack enfocado en software operativo: integraciones ERP, herramientas internas, automatización de procesos, dashboards, booking, stock y productos web autohospedados.

## Enfoque

- Entender el proceso real antes de escribir código.
- Separar lectura, escritura, snapshots y estados propios cuando hay sistemas legados.
- Diseñar APIs con permisos, validación, trazabilidad y límites claros.
- Publicar sólo cuando hay evidencia: capturas, tests, runbooks o métricas verificables.

## Stack principal

- Frontend: React, Next.js, TypeScript, Tailwind CSS.
- Backend: Node.js, NestJS, Express, Zod.
- Datos: PostgreSQL, SQL Server, Prisma, Drizzle, consultas read-only e importadores.
- Infra: Docker Compose, Linux, Cloudflare Tunnel, GitHub Actions.
- Calidad: Playwright, Vitest, pytest, Axe, CodeQL, secret scanning.

## Proyectos destacados

- Peluqueria Agenda: MVP privado con roles, agenda, booking público, confirmación/cancelación por email y reportes.
- Consulta Stock General: consulta web de stock contra ERP SQL Server, con superficies interna y externa.
- Calculadora Materiales Anclaflex: cotizador público con motor de cálculo backend, snapshots y PDF.
- Sector 07 Control: mesa operativa interna para pedidos ERP, snapshots PostgreSQL y estados trazables.
